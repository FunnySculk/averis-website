# Averis — официальный сайт проекта

Тёмно-фиолетовый сайт Minecraft-проекта **Averis**, оформленный в стиле присланного арта с парящими островами.

**Сайт:** https://funnysculk.github.io/averis-website/

## Страницы

- `index.html` — главная: знакомство с миром, особенности, сюжет, арт проекта и ответы на вопросы.
- `rules.html` — отдельная страница с базовыми правилами сервера и навигацией по шести разделам. **Это предварительная редакция**, не окончательное утверждение регламента.

## Дизайн и изображения

- `averis-theme.css` — фиолетовая палитра, адаптивная верстка, оформление элементов.
- `assets/averis-logo.webp` — прозрачный логотип, выделенный из изображения владельца.
- `assets/averis-world.webp` — оптимизированный оригинальный арт, присланный владельцем.
- `assets/averis-logo.svg` — векторный вариант логотипа.
- `assets/averis-world.svg` — дополнительная векторная сценография с островами и звездами.
- `favicon.svg` — символ Averis.

## Изменения

Обычные HTML, CSS и JavaScript, без npm и сборки. Можно открывать файлы локально или редактировать прямо в GitHub.

При обновлении файлов ветки `main` GitHub Pages автоматически обновляет сайт. Настройки: **Settings → Pages → Deploy from a branch → main → /(root)**.

**Перед запуском:** уточните окончательные правила, дату открытия, адрес сервера, ссылку на Discord и готовый релиз лаунчера. Не публикуйте неподтвержденные даты и ссылки.

Сайт независимого Minecraft-проекта, не связан с Mojang или Microsoft.
