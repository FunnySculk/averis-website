# Averis Website

Официальный сайт Minecraft-проекта **Averis**.

## Запуск

Сайт статический: откройте `index.html` в браузере. Сборка, Node.js и зависимости не нужны.

## Публикация

GitHub Pages → Settings → Pages → **Deploy from a branch** → **main** → **/(root)** → Save.

Ожидаемый адрес после включения Pages:
https://funnysculk.github.io/averis-website/

## Содержимое

- `index.html` — адаптивная страница, встроенные стили и JavaScript
- `favicon.svg` — значок вкладки
- `.nojekyll` — отключение обработки Jekyll на GitHub Pages

## Обновление

Меняйте тексты и стили в `index.html`; публикация обновится при следующем коммите в ветку `main`.

Адрес сервера, дата открытия, Discord и ссылка на готовый лаунчер намеренно не указаны без подтверждения. Ссылку на лаунчер можно добавить после появления релиза.

Неофициальный проект сообщества Minecraft, не связан с Mojang или Microsoft.
